## MyBlog-pet

MyBlog-pet is a blog site built in pure PHP.

Website functionality

- Authorization and Registration
- Adding, Editing and Deleting categories for posts
- Adding, Editing and Deleting posts
- Adding, Editing and Deleting users
- Simple search posts on the site by keywords


## Development tools

The following tools and technologies were used to develop this site:

- PHP v.8.2
- The layout was created using [Bootstrap](https://getbootstrap.com).
- MySQL was used as the database management system.
- The interaction with the database was created using PDO.
